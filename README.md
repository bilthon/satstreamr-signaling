# satstreamr-signaling

WebSocket signaling server for [satstreamr](https://github.com/bilthon/satstreamr) — a peer-to-peer metered live video streaming platform. This server only relays WebRTC offer/answer/ICE-candidate messages between a streamer and a viewer; it sees no media and no payment data.

See the [satstreamr README](https://github.com/bilthon/satstreamr) and [INSTALL.md](https://github.com/bilthon/satstreamr/blob/main/INSTALL.md) for setup instructions and the overall architecture.
